CAN — a shared bus with priorities
==================================

  node ── CANH ═══════════════ CANH ── node
  node ── CANL ═══════════════ CANL ── node
        120Ω                    120Ω   (both ends)

Classic frame (what software sees)
  id 11-bit (std) or 29-bit (ext) · RTR · DLC
  0..8 data bytes
The controller adds SOF, CRC-15, ACK slot,
EOF and bit stuffing (after 5 equal bits,
one opposite bit).

Arbitration
  all start together; a 0 (dominant) beats
  a 1 → LOWER ID WINS, no collision, no loss.
  The id is the priority, not an address.

ACK: any node that got the frame right pulls
the ACK slot dominant. A lone node never gets
ACKs → error counters climb → bus-off.

Bit rates: 125k, 250k (J1939), 500k (cars),
1M. Every node must match.

ESP32 TWAI = CAN 2.0 controller; needs a
transceiver (SN65HVD230 at 3.3 V).

Gotchas
  • one node alone: sends fail (no ACK)
  • missing terminators: errors at speed
  • OBD-II: request 7DF, replies 7E8..7EF

Export pcap → Wireshark decodes SocketCAN.
