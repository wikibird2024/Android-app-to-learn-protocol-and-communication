The ESP32 bridge — the phone's missing ports
============================================

  phone ── Wi-Fi TCP :3333 ──┐
        ── USB serial ───────┤   ESP32
                             ▼
     text line protocol → command table
       i2c · spi · can (TWAI) · ow (1-Wire)
       wifi · espnow · zb (C6) · ot (C6)

Protocol (same over TCP and serial)
  request  "<id> <command> <args>\n"
  reply    {"id":7,"ok":true,"data":...}
  error    {"id":7,"ok":false,"error":"..."}
  event    {"event":"can","id":"123",...}

Text on purpose: type the same commands in any
serial terminal; boot logs show up as console
lines and are not mistaken for replies.

First start
  no Wi-Fi saved → bridge opens access point
  "protolab-bridge", address 192.168.4.1.
  Use the Wi-Fi setup tool to join your
  network; it is then found by mDNS as
  _protolab._tcp.

Commands: type "help" in the Talk tab.
