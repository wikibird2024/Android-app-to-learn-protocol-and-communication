HTTP/1.1 — text lines over TCP
==============================

  request                      response
  GET /api/status HTTP/1.1     HTTP/1.1 200 OK
  Host: 192.168.1.50           Content-Type: application/json
  Accept: application/json     Content-Length: 15
  <blank line>                 <blank line>
                               {"temp": 21.5}

The blank line (\r\n\r\n) ends the headers.
Body length: Content-Length, or
Transfer-Encoding: chunked (size in hex, then
data, ... "0" ends), or the server closes.

Methods  GET read · POST create/act · PUT replace
         PATCH change · DELETE remove
Status   2xx ok · 3xx go elsewhere · 4xx your
         request is wrong · 5xx server failed

This tool writes the request bytes itself over
a TCP (or TLS) socket with "Connection: close",
so the Inside tab shows exactly what went on
the wire.

ESP32 tips
  • esp_http_server serves one request at a time
  • keep JSON small: RAM is tight
  • REST = nouns in the path, verbs as methods:
    PUT /api/led {"on":true}

Try
  GET http://httpbin.org/get, then look at the
  chunked or Content-Length body in Inside.
